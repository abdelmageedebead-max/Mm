ZENOVA V3 — مخصص للاستضافة السحابية
التقنية: Node.js + Express + PostgreSQL + QR.
النشر المقترح: Render أو أي خدمة تدعم Node.js وPostgreSQL.
Render: أنشئ PostgreSQL ثم Web Service من المشروع.
Build: npm install
Start: npm start
Environment: DATABASE_URL = رابط قاعدة PostgreSQL
PUBLIC_BASE_URL = رابط الموقع العام مثل https://your-app.onrender.com
الدخول الأول: admin / Admin@12345
غيّر كلمة المرور قبل الاستخدام الفعلي.
ملاحظة: شروط الخطط المجانية تتغير، تحقق من مزود الاستضافة قبل الاعتماد التجاري.
